    **Part B: Update ChatMessage.tsx**

    Add sub-agent pipeline visualization to AI messages. The approach:

    1. Import `PIPELINE_STAGES` from `@/app/types/types`.
    2. Inside the `ChatMessage` component, after `hasAttachments` computation, add pipeline stage detection:
       ```typescript
       // Detect pipeline stage markers in AI message content
       const detectedStage = useMemo(() => {
         if (isUser || !messageContent) return null;
         for (const stage of PIPELINE_STAGES) {
           if (messageContent.includes(stage.marker)) return stage.id;
         }
         return null;
       }, [isUser, messageContent]);
       ```
    3. In the AI message rendering section (the `isAi` branch, inside `hasContent && (...)` block), add a pipeline indicator ABOVE the markdown content:
       ```typescript
       {/* Pipeline stage indicator */}
       {detectedStage && (
         <div className="mb-2 flex flex-wrap gap-1.5">
           {PIPELINE_STAGES.map((stage) => (
             <span
               key={stage.id}
               className={cn(
                 "inline-flex items-center rounded-full px-2 py-0.5 text-xs font-medium",
                 stage.id === detectedStage
                   ? "bg-primary text-primary-foreground"
                   : "bg-muted text-muted-foreground",
               )}
             >
               {stage.label}
             </span>
           ))}
         </div>
       )}
       ```
    4. The indicator shows all 7 stages as small rounded pills. The active stage gets `bg-primary` styling (highlighted). Inactive stages get `bg-muted` styling (dimmed). This provides immediate visual feedback about which pipeline stage the agent is currently executing.

    Keep all existing rendering logic intact. The pipeline indicator only appears on AI messages that contain stage markers. Messages without markers render exactly as before.
