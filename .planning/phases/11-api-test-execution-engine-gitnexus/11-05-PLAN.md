    - Activation triggers (when the agent should use this skill)

    - Templates (output format templates)
    - Quality standards (what "done" looks like)

    **1. planner/SKILL.md** (~100 lines) - API test plan generation expert:
    - Role: Translates OpenAPI specs into comprehensive test plans
    - Triggers: User provides spec URL, asks for test plan, uses "plan" keyword
    - Procedure: Analyze spec -> Identify test scope -> Prioritize endpoints -> Define test matrix (positive/negative/boundary/security) -> Estimate effort
    - Template: Test plan with endpoint table, priority matrix, coverage targets
    - Quality: Every endpoint must have >= 3 scenarios, security tests for all auth endpoints

    **2. generator/SKILL.md** (~120 lines) - Test code generation expert:
    - Role: Generates executable test scripts from test plans/scenarios
    - Triggers: User asks to generate scripts, convert plan to code
    - Procedure: Read plan -> Select template (Playwright/Jest/Pytest) -> Generate per-scenario scripts -> Add assertions -> Validate syntax
    - Template: Playwright TypeScript test script with test.step, soft assertions, error capture
    - Quality: Scripts must pass check_script_syntax, follow naming convention, include setup/teardown

    **3. scenario/SKILL.md** (~120 lines) - Scenario test expert:
    - Role: Designs multi-step business flow tests with data dependencies
    - Triggers: User describes business flow, multi-API sequence, end-to-end scenario
    - Procedure: Identify flow -> Map API sequence -> Define data flow between steps -> Add assertions per step -> Handle error scenarios
    - Template: Scenario definition with steps, data mappings, extractors, assertions
    - Quality: Every data mapping must have source + target path, assertions must be specific (no "status is OK")

    **4. executor/SKILL.md** (~100 lines) - Test execution and result analysis expert:
    - Role: Executes tests and provides detailed result analysis
    - Triggers: User asks to run tests, execute scenario, check results
    - Procedure: Pre-flight checks -> Execute -> Parse results -> Categorize failures -> Generate summary
    - Template: Execution report with pass/fail/skip counts, failure analysis, coverage metrics
    - Quality: Must distinguish between test failures and infrastructure failures

    **5. healer/SKILL.md** (~100 lines) - Test fix expert:
    - Role: Diagnoses and repairs failing API tests
    - Triggers: User reports failing test, asks to fix, mentions flaky tests
    - Procedure: Analyze failure -> Classify root cause (API change, data issue, env issue, test bug) -> Propose fix -> Validate fix -> Update script
    - Template: Diagnosis report with root cause, fix description, validation results
    - Quality: Must preserve test intent, only modify assertion values when API contract changed

    **6. reporter/SKILL.md** (~100 lines) - Test report generation expert:
    - Role: Generates comprehensive test reports with coverage analysis
    - Triggers: User asks for report, summary, coverage metrics
    - Procedure: Collect results -> Calculate coverage (endpoint, method, status code) -> Identify gaps -> Generate visual report -> Suggest improvements
    - Template: Coverage report with endpoint matrix, status code matrix, gap analysis
    - Quality: Reports must include actionable recommendations, not just data
