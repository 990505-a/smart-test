    ```python
    GET /{id} — Detail
    PATCH /{id} — Update (body: APITestUpdate)
    DELETE /{id} — Delete

    GET /{id}/script — Download test script (returns file content as text)
    PUT /{id}/script — Update test script content (body: {content: str, script_format?: str})
    POST /{id}/run — Execute API test (body: {execution_config?: dict}), returns run with status=pending
    GET /{id}/runs — List test run history (query: limit)
    GET /{id}/runs/{run_id} — Get test run detail
    GET /{id}/runs/{run_id}/results — Get test results for a run
    ```

    Follow the existing pattern from test_cases.py and test_runs.py:
    - Use `_svc = APITestService()` module-level instance

    - Handle errors with HTTPException(404) for not found
    - For script upload/download, use plain text response types

    ```python
    GET /{id} — Detail (includes steps and variables)

    GET /steps/{step_id} — Get step

    PUT /{id}/steps/{step_id} — Update step
    DELETE /{id}/steps/{step_id} — Delete step (auto-reorder)
    POST /{id}/steps/reorder — Reorder steps (body: {step_ids: list[str]})

    POST /{id}/execute — Execute scenario (body: {mode: "sync"|"async", execution_config?})
    GET /{id}/runs — List execution records (query: limit)
    ```
