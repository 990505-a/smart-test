    import shutil
    from pathlib import Path

    Define constant: `SUBDIRS = ["api", "web", "testcase", "attachments", "scripts"]`

    Class `WorkspaceService`:
    - `__init__(self, db: AsyncSession)` -- sets `self.repo = WorkspaceRepository(db)`
    - `_ensure_default(self) -> None` (async) -- checks `await self.repo.count()`, if 0 creates default workspace with slug="default", name="Default", description="Default workspace", is_default=True
    - `_slugify(name: str) -> str` (static) -- converts to URL-safe slug: `re.sub(r"[^a-z0-9]+", "-", name.lower()).strip("-")`, returns "workspace" if result is empty
    - `list_workspaces(self) -> list[WorkspaceInfo]` (async) -- calls `_ensure_default()`, then `self.repo.get_all(offset=0, limit=100)`, maps each to WorkspaceInfo
    - `create_workspace(self, data: WorkspaceCreate) -> WorkspaceInfo` (async):
      1. Derive slug from `data.slug or self._slugify(data.name)`
      2. Check uniqueness via `self.repo.get_by_slug(slug)`, raise ConflictException if exists
      3. Create DB record via `self.repo.create(slug=slug, name=data.name, description=data.description, is_default=False)`
      4. Provision directories: `workspace_dir = settings.workspace_dir / slug`, create each subdirectory in SUBDIRS with `mkdir(parents=True, exist_ok=True)`
      5. Copy skills from default workspace: for each of `["api/skills", "web/skills"]`, `src = settings.workspace_dir / "default" / agent_subdir`, `dst = workspace_dir / agent_subdir`, if src.exists() and not dst.exists(): `shutil.copytree(src, dst)`
      6. Return WorkspaceInfo.model_validate(workspace)
    - `delete_workspace(self, slug: str) -> str` (async):
      1. Get workspace via `self.repo.get_by_slug(slug)`, raise NotFoundException if None
      2. If workspace.is_default: raise ConflictException("Cannot delete the default workspace")
      3. Remove directory: `workspace_dir = settings.workspace_dir / slug`, if exists: `shutil.rmtree(workspace_dir)`
      4. Delete DB record via `self.repo.delete(workspace)`
      5. Return `f"Workspace '{slug}' deleted successfully"`
