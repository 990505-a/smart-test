Web Functions API (prefix: /projects/{projectId}/web-functions):
- POST "" -> body: {project_id, folder_id?, display_name, name, description?, base_url?, business_module?, navigation?, pages?, tags?, custom_config?} -> {success, data: WebFunctionInfo}
- GET "" -> query: {p, page_size, folder_id?, search?} -> PaginatedResponse<WebFunctionInfo>
- GET "/{id}" -> {success, data: WebFunctionInfo}
- PATCH "/{id}" -> body: partial update -> {success, data: WebFunctionInfo}
- DELETE "/{id}" -> {success, message}
- GET "/{id}/sub-functions" -> query: {p, page_size} -> PaginatedResponse<WebSubFunctionInfo>
- POST "/{id}/sub-functions" -> body: {display_name, name, ...} -> {success, data}

Web Tests API (prefix: /projects/{projectId}/web-tests):
- POST "" -> body: {project_id, folder_id?, function_id?, sub_function_id?, name, description?, ...} -> {success, data}
- GET "" -> query: {p, page_size, function_id?, sub_function_id?, search?} -> PaginatedResponse
- GET "/{id}", PATCH "/{id}", DELETE "/{id}"
- POST "/{id}/run" -> {success, data: WebTestRunInfo}
- GET "/{id}/runs", GET "/{id}/runs/{runId}", GET "/{id}/runs/{runId}/results"

Configurations API (prefix: /configurations):
- POST "" -> body: {name, os?, os_version?, device?, browser?, browser_version?, is_system?, description?}
- GET "" -> query: {p, page_size} -> PaginatedResponse
- GET "/{id}" (id is integer), PATCH "/{id}", DELETE "/{id}"
- GET "/system" -> {success, data: ConfigurationInfo[]}
