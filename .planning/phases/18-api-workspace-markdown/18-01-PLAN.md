1. Create `src/app/api/v2/reports.py` — a new FastAPI router with prefix="/reports" containing two GET endpoints.

   **Endpoint 1: GET /sessions**
   - Function: `list_sessions() -> dict`
   - Resolve base path: `settings.workspace_dir / "default" / "testcase" / "workspace"`
   - If base does not exist, return `{"success": True, "data": []}`
   - Iterate `base.iterdir()`, sorted reverse (newest first)
   - For each item that is a directory: collect all `.md` files where `f.suffix == ".md" and f.is_file()`, sorted by name (phase*.md files first using sort key `(0 if n.startswith("phase") else 1, n)`)
   - Only include directories that have at least 1 .md file
   - Return each session as: `{"name": item.name, "files": [list of filenames], "file_count": len(md_files)}`
   - Response: `{"success": True, "data": sessions}`

   **Endpoint 2: GET /sessions/{session_name}/files/{file_name:path}**
   - Function: `get_report_content(session_name: str, file_name: str) -> dict`
   - Resolve base: `_get_reports_base().resolve()`
   - Build file_path: `(base / session_name / file_name).resolve()`
   - **SECURITY** — Path traversal check: `if not file_path.is_relative_to(base): raise HTTPException(403, "Access denied")`
   - Check file exists and is_file: `raise HTTPException(404, "File not found")`
   - Check suffix is .md: `raise HTTPException(400, "Only .md files are supported")`
   - Read content: `file_path.read_text(encoding="utf-8")`
   - Return: `{"success": True, "data": {"name": file_name, "session": session_name, "content": content}}`

   Helper function: `_get_reports_base() -> Path` returns `settings.workspace_dir / "default" / "testcase" / "workspace"`

   Imports: `logging`, `pathlib.Path`, `fastapi.APIRouter`, `fastapi.HTTPException`, `src.app.core.config.settings`

   Follow the code style from `src/app/api/v2/wikis.py` — module docstring, logger, router with prefix.
