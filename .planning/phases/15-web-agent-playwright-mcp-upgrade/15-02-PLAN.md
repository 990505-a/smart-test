5. **make_agent() rewrite**: The critical change -- replace the stub with the full MCP integration:

```python
@asynccontextmanager
async def make_agent() -> AsyncIterator[Pregel]:
    """Create Web test agent with Playwright MCP tools via stdio session.

    Uses session-level MCP pattern (not client-level like API agent)
    because Playwright Test MCP requires persistent browser state.
    """
    context_middleware = WebContextInjectionMiddleware()

    # Create MCP client for Playwright Test MCP server
    client = MultiServerMCPClient({
        "web_mcp": {
            "transport": "stdio",
            "command": "cmd",
            "args": ["/c",
                     f"cd {settings.web_mcp_root_resolved} & ",
                     "npx", "playwright", "run-test-mcp-server"],
        }
    })

    # Session-level pattern -- browser state persists for agent lifetime
    async with client.session("web_mcp") as session:
        mcp_tools = await load_mcp_tools(session)
        all_tools = mcp_tools + WEB_AGENT_TOOLS

        # Targeted error handling -- only browser tools, not DB tools
        all_tools = wrap_tools_with_error_handling(
            all_tools,
            tool_patterns=["browser_", "playwright-test/"]
        )

        web_agent = create_agent(
            model=llm,
            tools=all_tools,
            system_prompt=SYSTEM_PROMPT,
            middleware=[skills_middleware, context_middleware],
            backend=composite_backend,
            context_schema=WebAgentContext,
        )

        yield web_agent
```

Key differences from API agent pattern:
- Uses `client.session("web_mcp")` + `load_mcp_tools(session)` (session-level)
- NOT `load_mcp_tools(client, server_name="web_mcp")` (client-level)
- MCP tools come FIRST: `mcp_tools + WEB_AGENT_TOOLS`
- Error handler targets only browser tools: `tool_patterns=["browser_", "playwright-test/"]`
- No try/except graceful degradation -- if Playwright MCP fails, the agent cannot function (it needs browser tools)
- Keep `agent = make_agent` export at bottom

6. **WebAgentContext**: Keep unchanged (same dataclass from Phase 14).
