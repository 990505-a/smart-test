- **2026-09-21 22:05** · 领域知识 · _agent_

  **截图能力的边界（问剑长生实测，2026-09-21）**：进入创角界面 / 游戏内之后，`unity_screenshot` 只拍得到 3D 模型与场景渲染，**UI 完全不入镜**（启动登录界面时 UI 是能拍到的）。此时"界面长什么样"不能靠截图判断，要用 `unity_hierarchy` / `unity_find_by_text` / `unity_object_text` 读对象树——本次创角全程（选择角色→下一步→进入预览→输入名称→踏入仙途→启程）都是靠对象状态确认的，截图里只有角色模型在动。所以**先信对象树，截图只作辅助**。
