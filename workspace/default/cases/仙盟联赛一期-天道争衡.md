# 仙盟联赛一期-天道争衡 测试用例集（2026.08.30.23.25）

## 1. 前置准备

### 1.1 配置表清单

| 表名 | 用途 |
|---|---|
| gang_season_time | 赛季时间与玩法模块（module=3 为天道争衡，season_id=5） |
| gang_season_config | 联赛通用常量（bet_change_number=-0.5/2.25、bet_base_user_count=50、bet_lose_return=0.3） |
| gang_season_vein_congress_config | 定时赛事战斗常量（灵阵/战勋/灵气/爆发/buff/战场人数上限） |
| gang_season_vein_config | 逐鹿与蕴养常量（宣战/争夺时段、上限、积分、奖励补发） |
| gang_season_vein | 灵脉点位表（8 条，declare_num=300，name 为 i18n 占位） |
| gang_season_vein_arise | 蕴养节点表（支脉/主脉、消耗、buff） |
| gang_season_vein_fight_reward | 逐鹿排名奖励表（level+rank_range+order） |
| gang_season_vein_mission | 天道赐运事件表 |
| gang_union_config | 联赛期逐出/退出/加入人数限制 |
| activity_custom_stage | 赛季阶段流程节点 |

### 1.2 GM 指令与环境

| 项 | 说明 |
|---|---|
| GM 面板 | 宗门赛季相关指令见 server/game_server/game/gm/gm_gang_season.gs 与 GangSeasonGmD、VeinCongressGmD、GangSeasonVeinGmD（跳阶段/重开瑞士轮/推进逐鹿阶段/补结算/仙盟解锁放行 gm_union_unlock 等），执行前以面板实际指令名为准 |
| 测试环境 | 多服（至少 3 服，含已开仙盟与未开仙盟服）、多账号（盟主/副盟主/普通成员/多管理职务）、至少 2 个仙盟（各含 2~3 宗门）+ 若干落单宗门，总参赛单位 ≥34 以验证四档分档 |
| 数值口径 | 全部以 /repo/server/game_server/json_etc/gang_season_vein*.json 当前配置为准（宣战/争夺 08:05-22:00、进攻上限 10 次、主脉汇总 Sat 20:20、补发 120000 秒等） |

### 1.3 参赛单位口径

| 项 | 说明 |
|---|---|
| 双单位形态 | 仙盟（UNION，星级=成员宗门星级和，满 5 星）与宗门（CLAN） |
| 多实体命名 | A/B/C 玩家，宗门 1/2/3（分属服务器 S1/S2），仙盟 X=宗门1+宗门2、仙盟 Y=宗门3+落单宗门4 |
